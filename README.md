# Customer-Segmentation-using-RFM-Analysis


📊 Customer Segmentation using RFM Analysis
📌 Project Overview

This project focuses on customer segmentation using the RFM (Recency, Frequency, Monetary) analysis technique. It helps businesses identify high-value customers and improve marketing strategies based on customer behavior.

🎯 Objectives
Analyze customer purchasing patterns
Segment customers based on RFM scores
Identify loyal, at-risk, and potential customers
Visualize insights using dashboards
🛠️ Tools & Technologies
Power BI
Data Analysis
Data Visualization
RFM Model
📂 Dataset
Customer transaction dataset (sales, purchase frequency, dates, etc.)
📊 Key Features
RFM score calculation (Recency, Frequency, Monetary)
Customer segmentation (High-value, Medium-value, Low-value)
Interactive Power BI dashboard
Business insights for decision-making
